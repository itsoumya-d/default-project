## Quality gaps (ranked by hiring-signal impact)

1. **No model artifacts on Hugging Face (0 models).** Every other runnable suite
   can be described as "code + benchmark", but Anthropic/Google/OpenAI-style
   signals point at *trained weights/LoRAs with cards*. Fix: publish the
   `2026-11-03-rl-base-100-corrected` LoRA + a `heros-rlvr-qwen2.5-coder-1.5b`
   model card (needs HF token — blocked, see handoff).
2. **Research subdirectories are empty stubs.** `research/papers/`,
   `research/literature_reviews/`, `research/benchmarks/` each contain only a
   `README.md` saying "empty / no benchmark has been run". `RESEARCH_LIBRARY.md`
   holds 1-line cards; no per-paper note contains claim/equation/experiment/
   limitation/reproduction task as the directory's own rules demand.
3. **Cross-project benchmark does not exist.** No single command runs the
   portfolio's test suites and emits one comparable results table with
   hardware/seed/command stamps (`benchmarks/README.md` rules). Fix: this
   session's `research/benchmarks/run_cross_project_bench.py` (produces
   `RESULTS_2026-11-09.md` + JSON).
4. **Reflexion-SWE has no Lite-50 run and no persistent skill library.**
   `project-03-.../README.md` says so explicitly; only a toy ablation
   (`experiments/toy_ablation.json`) exists. Highest-leverage missing experiment.
5. **P01 RL-from-base shows no gain, and risk calibration is broken.**
   100-step RL-from-base (Qwen2.5-Coder-1.5B, LoRA r16, RTX 2060):
   ok_rate **0.20 (10/50)** vs base **0.20**; mean reward 0.13 vs 0.02; error
   codes dominated by REQUIREMENT_MISS (33/50) and SQL_EXEC_ERROR (7/50);
   risk_accuracy **0.10**, decision_accuracy **0.50**. The failure mode is
   *requirement understanding + risk-tier prediction*, not format/SQL shape —
   reward shaping should target those two terms.
6. **Profile README is static.** 28 KB, well-written, links to HF — but contains
   no `update-readme` markers, no auto-synced CI status/activity block, no
   structured "latest experiments" table. Fix: this session's
   `profile-readme/` staging (sync script + workflow + markers), pending push.
7. **Newly cloned repos need README/RESULTS depth check** (they were cloned
   depth-1 this session; scaffolds `genai-tooling-evals`, `eleven-platform-core`,
   `recare-ai-platform` are <20 KB — candidate "finish or archive" decisions).
8. **`HEROS-RL` SFT adapter (`a3-500-qwen1.5b`) improves reward (0.13 vs 0.02)
   but no held-out comparison table vs base/SFT exists in one place.** The
   eval files exist per-run; nobody joined them.

  invalidated and rerun `rl-base-100-corrected`, not hidden.

  culture is real, not aspirational.
