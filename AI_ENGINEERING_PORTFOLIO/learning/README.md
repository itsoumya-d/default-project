# Learning — Deliberate Practice, Not Course Collecting

This directory tracks the skills required by `../FUTURE_AI_SKILLS_MAP.md` and
`../SKILLS_ROADMAP.md`. The unit of progress is a working artifact or a measured
result, not a completed video.

**Status:** scaffold. No course, book, or certification is claimed.

## Planned contents

| Path | Purpose | State |
|---|---|---|
| `papers/` | one-page notes with the equation, limitation, and a reproduction task | Planned |
| `exercises/` | small implementations tied to a project gate | Planned |
| `reviews/` | monthly self-review: shipped, slipped, learned | Planned |
| `reading_queue.md` | ordered queue with a reason for each item | Planned |

## Rules

- A paper note is not "read" until it names one assumption the paper does not
  test and one experiment that would falsify it.
- An exercise counts only if it has a test or a measurement.
- No certificate is listed as evidence of skill.
- Time-box reading to the question the current project needs answered.
